Install Suave

A smooth language for scripts, data and web apps. One line in the Terminal sets it all up!

curl -fsSL https://radii-office.com/suave/install.sh | sh

Works on a Mac or Linux. Open Terminal, paste the line, and press Enter. When it says Done!, open a new Terminal window and try suave eval "1 + 2".

What the line does

  1. Downloads Suave and checks the download against its published checksum, so a broken or changed file is refused.
  2. Installs Deno if you do not have it (Suave runs on Deno).
  3. Keeps Suave in ~/.suave and puts the commands suave, lake and laker in ~/.local/bin.
  4. Makes sure new Terminal windows can find them.

Update, remove, or read first

Update: run the same line again, or type suave upgrade.
Remove: ~/.suave/install.sh --uninstall
Read before you run: install.sh is a short, plain script. The download is suave.tar.gz and its checksum is suave.tar.gz.sha256.

Then try

suave new my-site --web then suave serve app.wsv makes a website, and laker init turns an app into a desktop program.
