Help Deck

📝 Line shortcuts: At the start of a line, type #, ## or ### and a space for headings, #### for the big mega header, * for a bullet, or > for a quote!

🖍️ Gel highlights: The Annotator's first three tools are Keydown too! Type #R#text## for a highlight strip, #R#text#_ for a gel underline and #R#text#~ for a gel strike, then a space! Colors: R O GL Y L G TU T C B PR PK SL!

💊 Gloss Pills: The Bubble Chips' pill-shaped sibling! Type %B%text% then a space, with the same 16 colors as Bubble Chips: C O G R PR PK Y B L T GL SL W BK FG TU!

🚩 Gel Flags: Another Bubble Chip cousin! Type #%R%text% then a space, with the same 16 colors as Bubble Chips!

🟡 Gel Orbs & Highlighters: Select any text and pick a color tile from the dropdowns to apply custom styles.

📦 Megachips & Badges: Use advanced tags like plasma pods, glass brackets, and circuit nodes.

🚪 Exiting formatting: Press Cmd/Ctrl+Shift+E to hop out of any style, type \ + space to break out to the right, or hit Enter inside an empty chip for a fresh line!

💾 YAML Export: Save your workspace anytime into a clean .kn snapshot file.

⬇️ Download...: Export your note as .kn, .pdf, .docx, .odt, .txt, .epub, .jpg, .svg, or a web .zip!

🏷️ Tags: Hit the Tags button up top to drop in a user tag, a dropdown chip with your own options, or a date tag!

📝 Notes: Add tabs for separate notes — each keeps its own outline, and all travel inside one .kn file!
