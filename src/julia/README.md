# Julia API backend, powered by the Oxygen.jl package!

Real Julia executing over HTTP — the backend half of the multilingual story!
The static site never calls it (static hosting has no host for it), so this
stays a dev/optional service: run it, hit it, trust it!

Setup once (UUIDs generated by Pkg, never hand-written):
```sh
julia --project=julia -e 'using Pkg; Pkg.add(["Oxygen", "HTTP", "JSON3"])'
```

Run:
```sh
julia --project=julia julia/serve.jl   # serves http://localhost:8000 !
```

Routes (all verified live against the known answers):
- `GET /health` → `{"status":"ok","engine":"julia-oxygen"}`
- `POST /api/evaluate` with `{"A1":"10",...,"A4":"=SUM(A1:A3)",...}` →
  evaluated sheet (`A4=60.0`, cycles → `ERROR:CYCLE`, bad → `ERROR`)!
- `POST /api/stats` with `{"values":[10,20,30,60,30]}` →
  count/sum/mean/min/max (`mean=30.0`)!

Files:
- `serve.jl` — Oxygen.jl routes plus a compact formula engine twin!
- `Project.toml` + `Manifest.toml` — Pkg-resolved dependencies!
